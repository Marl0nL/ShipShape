Trust a machine

On that machine, make a key (ssh-keygen -t ed25519 -f ~/.ssh/shipshape/id_ed25519) and paste the one line of its .pub file here. FleetLedger writes the machine's bundle (its certificate, SSH config and the CA line): Download bundle in its row (on that machine: tar xzf shipshape-NAME.tar.gz && sh shipshape-NAME/install.sh), or copy its folder over and run sh install.sh there. Download it again to renew the certificate.
