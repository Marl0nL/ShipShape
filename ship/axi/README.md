# ship/axi

`ship-axi` (W7): a small AXI tool in Node (axi-sdk-js, pinned in `versions.toml`)
that tells agents about their Ship. It reads `/run/shipshape/status.json`
(`contracts/ship-status.schema.json`). Phase 1: home view, `rules`,
`setup hooks`; `request` and `message` print "not available yet".
